# Weekly Claims Pulse Workflow

A repeatable workflow that produces a “Claims Pulse” style update each week.

## 1. Input

- Weekly or rolling claims dataset (or a set of summary metrics).
- Basic business context (e.g., Commercial Auto, Mid-Market, region).

## 2. Insurance Ops Analyst Agent

- Calculates and reviews:
  - Loss Ratio
  - Frequency and Severity
  - Claim closure rate
  - Time to close / cycle times
  - Any changes WoW or MoM
- Identifies:
  - 2–3 key problem areas.
  - 1–2 positive stories.

**Output:**  
“What / Why / Now What” summary + 3–5 GenAI questions.

## 3. Demo Architect Agent (Optional)

- Takes the claims insights and:
  - Frames them as part of an executive dashboard.
  - Designs a Pulse/Agentforce story:
    - Show metric change → ask why → show drivers.
  - Adds this to a Book of Business or Claims Ops demo.

**Final Outcome:**  
A weekly claims briefing that can be read directly or used as the script for a GenAI-augmented Tableau demo.
