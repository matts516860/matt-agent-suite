# Example Prompts for the Agent Suite

You can use or adapt these prompts directly with the corresponding agents.

---

## Demo Architect Agent

- “Turn these discovery notes into a full Tableau + Agentforce demo for an insurance carrier, with Advisor, Underwriter, and Executive personas.”
- “Design a Book of Business demo that shows RMDs due, open complaints, and upcoming meetings, with clear AI touchpoints.”
- “Create the semantic model blueprint and demo script for a TIAA-like advisor console.”

---

## Dataset Engineer Agent

- “Generate a 10,000-row underwriting submissions dataset with worsening submission quality in Q2 for small commercial lines.”
- “Create a Nuveen-like sales dataset with affiliates, asset classes, and products, including at least one underperforming segment.”
- “Build a claims dataset with rising severity but stable frequency over the past 18 months.”

---

## Tableau Cloud Ops Agent

- “Given these Admin Insights metrics, tell me who should be Explorers vs Viewers and why.”
- “Summarize performance issues and give me three concrete steps to reduce load on VizQL.”
- “Rewrite this technical Slack thread as an executive-friendly update.”

---

## Local App Builder Agent

- “Scaffold a Node/React application that:
   - lists fields from a Tableau data source,
   - lets the user select them,
   - sends a query through VizQL Data Service,
   - and forwards the results to a local LLM for explanation.”
- “Generate a simple API wrapper around VizQL Data Service using Express, with PAT-based auth.”

---

## Insurance Ops Analyst Agent

- “Analyze this dataset and explain why Loss Ratio is increasing for Mid-Market GL in the Northeast.”
- “Identify which brokers are driving higher Time to Bind and suggest actions.”
- “Produce Pulse-style insights for an underwriting portfolio review.”

---

## Trip Concierge Agent

- “Plan a 7-day trip from Northern California redwoods to Crater Lake to Portland, with kid-friendly activities and limited afternoon driving.”
- “Give me a one-day Long Island beach plan with backup rainy-day ideas.”

---

## Home & Life Assistant Agent

- “Help me plan an efficient way to improve heating/cooling in my finished basement without redoing all the ductwork.”
- “Create a Z3PlaysPC Hollow Knight content plan for three episodes.”
- “Design a 20-minute HIIT treadmill workout for me and a beginner-friendly version for my 11-year-old.”
