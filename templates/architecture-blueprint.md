# Architecture Blueprint Template

Use this to structure Demo Architect Agent outputs.

## 1. Executive Summary

- One or two paragraphs describing:
  - The business problem
  - The solution approach (Tableau + Agentforce)
  - Expected outcomes

## 2. Personas

- List key personas (e.g., Underwriter, Producer, Claims Manager, CFO).
- For each persona:
  - Goals
  - Pain points
  - Key metrics they care about

## 3. Data Model Requirements

- Overview of facts, dimensions, and relationships.
- Key KPIs and their definitions.
- Any special modeling notes (e.g., snapshot vs transactional).

## 4. Dashboards & Flows

- List of dashboards or experiences:
  - Book of Business
  - Claims Performance
  - Broker Performance
  - Executive Summary
- For each:
  - Primary questions it answers
  - Primary metrics visualized
  - Critical filters

## 5. AI / GenAI Interaction Points

- Where Pulse or Agentforce appears:
  - “Explain this spike in loss ratio.”
  - “Which brokers should I focus on this week?”
- Inputs and outputs:
  - What context is passed into the LLM
  - How the answer is displayed

## 6. Demo Script

- High-level walkthrough:
  - Starting point
  - 6–10 “beats” or steps
  - Closing takeaway

This template should be customized for each customer or internal demo.
